# Project 2: COVID-19 Data Analysis Dashboard — Excel

## Project Overview
This project uses Microsoft Excel to analyze and visualize COVID-19 data through an interactive dashboard. It presents key statistics related to cases, deaths, recoveries, testing, and population, helping users understand the impact of the pandemic across different countries and years.

## Key Features
- **Total Cases:** Displays the overall number of reported COVID-19 cases.
- **New Cases:** Highlights newly reported cases.
- **Total Deaths:** Tracks reported deaths associated with COVID-19.
- **Recoveries:** Shows reported recovery statistics.
- **Testing Analysis:** Presents COVID-19 testing information.
- **Interactive Filters:** Allows users to explore data by country and year.
- **Data Visualization:** Uses charts and summary indicators to make trends and comparisons easier to understand.

## Tools Used
- Microsoft Excel
- Data cleaning and organization
- Charts and data visualization
- Interactive dashboard filters

## Project Objective
To transform COVID-19 statistics into an interactive visual report that helps users explore pandemic trends and compare key health indicators across countries and time periods.
